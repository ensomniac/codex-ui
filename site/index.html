What it does

Work in the apps
you already use.

codex-ui connects a command-running agent to your Mac’s native desktop. It uses your existing windows and Chrome profile.

See and inspect

Capture a window or display. Read named controls. Inspect Chrome’s DOM and visible console entries.

Act on the interface

Press a button, enter text, move the pointer, or arrange windows. Group related actions in a JSON plan.

Check the result

Get structured output and a screenshot after an action. Coordinates account for Retina scaling and multiple displays.

Desktop control runs locally, without an account or hosted service. An activity indicator shows when the tool is working. It yields to your mouse or keyboard and restores the pointer when it finishes.

Get started

Ready for your Mac.

Run the installer in Terminal. It supplies uv and an isolated Python runtime, then installs the latest stable release.

macOS may request Accessibility, Screen Recording or Automation access for your terminal or agent app. doctor checks what is available.

Why it exists

Built on a working Mac.
Opened to everyone.

codex-ui began as a script Ryan used with his agent. He wanted others to have that same access to their own computers, and the ability to maintain the tool themselves.

His brief was direct: the agent should operate as the human, with the same access. The tool should stay fast and avoid adding layers of permission requests around authorized work.

A few useful details

Which agents can use it?

Any agent that can run a local command and inspect an image. Install the bundled skill for Codex or Claude, or give another agent the CLI schema and command guide.

Does it use my existing Chrome session?

Yes. It works with Chrome already open, including signed-in tabs and local files. DOM and console inspection temporarily uses DevTools, then restores its layout and the clipboard.

What leaves my computer?

Desktop operations run locally and send no telemetry. Installation and upgrades download software from GitHub and package providers. Your agent host controls how it handles images and command output.

How do updates work?

Run codex-ui upgrade. It checks the latest stable GitHub release, verifies the download and updates the installed runtime. Run codex-ui skill install afterward to refresh the skill.

Is this an OpenAI product?

No. codex-ui is an independent, MIT-licensed project by Ensomniac. It is not affiliated with or endorsed by OpenAI or Apple.
