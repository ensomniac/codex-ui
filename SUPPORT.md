# Get help or share a task

Native desktop control currently works on macOS 13+ on Apple Silicon and Intel. Start with the [first task](https://ensomniac.github.io/codex-ui/recipes.html#first-run) and run `codex-ui doctor` if setup is stuck.

- [Q&A](https://github.com/ensomniac/codex-ui/discussions/categories/q-a): setup questions, choosing a command, or understanding a result. Include the goal, command, version, and what happened.
- [Show and tell](https://github.com/ensomniac/codex-ui/discussions/categories/show-and-tell): a task you actually ran, the steps, and the observed outcome. Useful failures are welcome too.
- [Bug report](https://github.com/ensomniac/codex-ui/issues/new?template=bug.yml): a reproducible command failure or incorrect result.
- [Desktop task report](https://github.com/ensomniac/codex-ui/issues/new?template=desktop-task.yml): a particular app or workflow that gets stuck.

Remove tokens, private URLs, names, and other private content from command output and captures before posting. Support happens in this repository; there is no paid support requirement or guaranteed response time.

Want to contribute? Browse [good first issues](https://github.com/ensomniac/codex-ui/contribute) and read [CONTRIBUTING.md](CONTRIBUTING.md). You can open a useful PR without an issue or invitation.
