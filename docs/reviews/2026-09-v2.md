# Second edition: evaluation and implementation plan

September 10, 2026. Baseline: public 2.0.1, commit `af432bf`.

## Brief

Evaluate the product as it exists, make the findings actionable, implement the changes, and verify them. The second edition should use restrained typography, clear hierarchy, and careful spacing in the spirit of Apple's product pages and OpenAI's editorial presentation. Its own identity, founding language, and agent-maintained model remain intact.

## Implementation sequence

1. Establish the mark, typography, surfaces, spacing and human copy rules; rebuild the public page, guide, playground and README together.
2. Replace the illustrative result with a real local page interaction. Make installation and copy controls progressively enhanced.
3. Synchronize public release references; improve actual released-upgrade coverage.
4. Establish a bot-authored maintainer PR, review the final commit locally, and merge through the existing signed gate.
5. Release 2.1.0, upgrade Ryan's installation, and inspect the published desktop/narrow layouts and actual controller result.
